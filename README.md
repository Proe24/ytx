# YouTube Transcript Extractor

A tiny local web app. Paste a YouTube link, pick a language, get the text.

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Your browser opens at http://localhost:8765. Add `--no-browser` to skip that.

## How it works

1. Paste any YouTube link (watch, youtu.be, shorts, embed, live) or a bare 11-character video ID.
2. The app lists every caption track the video has. Tracks marked "auto" were generated by YouTube.
3. Optionally pick a translation target. YouTube translates on its side.
4. Get the transcript as plain text, with or without timestamps. Copy it or download a `.txt`.

Only videos with captions work. Private videos and videos with captions disabled return a clear error.
